# Imágenes de Ejercicios

Esta carpeta contiene las imágenes de los ejercicios de la biblioteca.

## Formato recomendado:
- **Formato**: PNG o JPG
- **Tamaño**: 400x400px o 800x800px (cuadradas)
- **Nombre del archivo**: Debe coincidir con el `id` del ejercicio en `/src/data/exercises.ts`

## Ejemplo:
Si tienes un ejercicio con id `press-banca-plano`, la imagen debe llamarse:
```
press-banca-plano.png
```
